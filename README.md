# STRYDE — Streetwear Studio

A premium concept store for a streetwear brand, inspired by an "Own the Street" fashion reel.
Static HTML, CSS and JavaScript with no build step.

## Highlights

- **Hero:** each slide has a floating cut-out figure in front of a giant headline that changes per slide. Props and pill tags pop in, joined by animated dotted lines. The hero has mouse parallax with a 3D tilt, swipe and keyboard controls, and an autoplay progress bar.
- **Motion:** loader and page-transition curtains, word-by-word headings, a scroll-speed marquee, a sticky story with parallax images, magnetic buttons, a custom cursor, hover image wipes and zoom on product images.
- **Store:** shop with category, colour and sort filters plus live search. Product pages have colour variants, sizes, a size chart and a sticky buy bar. You also get a wishlist, quick add, a bag drawer, promo codes (STRYDE15, FIRST10), checkout with standard or express delivery, order tracking and a demo account.
- **Pages:** Home, Shop, Product, Lookbook, About, Contact (map, form and FAQ), Bag, Checkout, Order, Wishlist, Account and 404.

The bag, wishlist, orders and account are stored in `localStorage`. No real orders are placed and no payment details are collected.

Photos are from Unsplash. The background cut-outs were made with an ISNet segmentation model.

## Run locally

```bash
python -m http.server 8000
```
